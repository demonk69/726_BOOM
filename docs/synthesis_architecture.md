# Synthesis Architecture

Gate 3.2 separates synthesis project creation from directives and uses one generated merged source for Vitis HLS 2021.2.

## Source Flow

| Flow | Source Form |
|---|---|
| Native g++ tests | Independent C++ source files |
| Vitis HLS csim trace harness | Independent C++ source files and testbench |
| Vitis HLS csynth | `src/boom_core_merged.cpp`, generated by `scripts/generate_merged.sh` |

`src/boom_core_merged.cpp` contains an `AUTO-GENERATED` marker and is regenerated before each csynth script runs.

## Tcl Split

| Script | Purpose |
|---|---|
| `scripts/create_project.tcl` | Generate merged source, create/open project, add files, create solution |
| `scripts/run_baseline_csynth.tcl` | Baseline `boom_core_top` csynth without `CORE_CYCLE` pipeline |
| `scripts/run_performance_csynth.tcl` | Separate performance experiment with `BOOM_HLS_ENABLE_CORE_PIPELINE=1` |
| `scripts/run_area_csynth.tcl` | Area experiment wrapper, currently conservative |
| `scripts/run_top_csynth.tcl` | Generic top-level csynth driver for diagnostics |
| `scripts/module_csynth.tcl` | Module diagnostic csynth Tcl |
| `scripts/run_module_csynth.sh` | Runs all module diagnostic tops and creates module logs |

## Directives

| File | Policy |
|---|---|
| `directives/baseline_directives.tcl` | No pipeline, no unroll, no complete array partition |
| `directives/performance_directives.tcl` | Uses the same function code; core pipeline is compile-macro gated |
| `directives/area_directives.tcl` | Conservative placeholder, no aggressive PPA directives |

The legacy `directives/baseline.tcl`, `directives/performance.tcl`, `directives/area.tcl`, and `scripts/run_csynth.tcl` are compatibility wrappers only.
