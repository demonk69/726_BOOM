# BOOM Verilator Trace Reference

This directory contains the Gate 2 trace schema and build/run scripts for the original BOOM SmallBoomConfig Verilator reference.

## Current Status

The original Chipyard simulator binary, source checkout, `libfesvr`, `libdramsim`, and RISC-V cross compiler are missing. This directory includes a standalone runner that links against the existing generated `VTestHarness__ALL.a`, supplies local DPI stubs, and uses hand-encoded `+loadmem=` images.

Five corrected standalone traces have been generated and checked under `reference/boom_traces/`: `independent_alu_commit.jsonl`, `raw_chain_cycle.jsonl`, `branch_taken_cycle.jsonl`, `branch_not_taken_cycle.jsonl`, and `nested_branch_cycle.jsonl`. They terminate through a retired store to configured `tohost` address `0x80000080` and are not max-cycle-truncated.

## Intended Flow

```sh
scripts/apply_trace_patch.sh
scripts/build_reference_programs.sh
scripts/build_boom_trace.sh
scripts/run_boom_trace.sh --loadmem tb/programs/boom_reference/build/independent_alu.hex --output reference/boom_traces/independent_alu_commit.jsonl --max-cycles 100000
scripts/check_boom_trace.sh reference/boom_traces/independent_alu_commit.jsonl
```

The trace patch is guarded by `BOOM_EQUIV_TRACE`. Without that compile macro, original BOOM functionality is unchanged. The current standalone path does not apply that patch; it observes the existing generated model from the runner.

## Trace Files

Empty, synthetic, or max-cycle self-loop traces must not be used for equivalence. The standalone runner is acceptable only when its output is generated by evaluating the original generated BOOM `VTestHarness` model and the trace has valid termination metadata. Full official-emulator equivalence still requires restoring the Chipyard/FESVR/DRAMSim path and running the with/without instrumentation noninterference check.
